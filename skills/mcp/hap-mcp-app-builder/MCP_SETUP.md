# HAP MCP 接入与异常排查指南

仅在未检测到 HAP MCP 服务、`401` 鉴权失败、工具数不足（`tools_count < 170`）或应用权限受阻时读取。修复后返回 [SKILL.md](SKILL.md) 复核连通并继续原任务。

> 安全边界：本指南仅作操作指引，**不要求用户在对话中发送明文个人访问令牌，Agent 也不提取令牌或修改宿主本地 MCP 配置文件**。

## 1. 未检测到 MCP 服务（`0 个`）
引导用户：前往明道云右上角点击 **「连接 AI」**，勾选 **「HAP 应用助手」** 并选择/创建个人访问令牌（开启「所有应用」与「所有接口」），按页面指引完成接入并在当前 AI 工具中刷新重连（Reload MCP）后告知继续。

## 2. 令牌失效或鉴权失败（`401`）
注意：单应用接口报 `10001 Http Headers verification failed` 多为 `appId` 为空，由 Agent 补传自愈，勿误判为令牌失效。
全局接口（如 `get_org_list`）报 `401` 时引导用户：前往明道云 **「连接 AI」** 或 **「个人头像 → 授权与访问 → 个人访问令牌」** 重新生成有效令牌，按页面指引更新当前 AI 工具中的 MCP 连接并刷新重连后告知继续。

## 3. 工具数量不全（`tools_count < 170`，非 Data 场景阻断）
引导用户：前往明道云 **「个人头像 → 授权与访问 → 个人访问令牌 → 编辑当前令牌」**，将 **「应用范围」** 设为 **「所有应用」**、**「接口范围」** 勾选 **「所有接口」** 保存，刷新重连 MCP 后告知继续。

## 4. 令牌与工具正常，但新建或访问应用被拒
勿让用户重装 MCP，依次引导核查：
1. **应用范围受限**：编辑当前令牌，将「应用范围」改为「所有应用」或勾选目标应用；
2. **环境/组织不匹配**：确认链接域名与所属组织已包含在当前令牌授权范围内；
3. **账号角色不足**：新建应用需组织开通「创建应用」权限；修改已有应用需该应用的「管理员 / 运营者 / 开发者」角色。
