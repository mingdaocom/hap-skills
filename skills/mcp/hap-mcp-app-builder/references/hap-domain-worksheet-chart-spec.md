# 工作表统计图规范

## 范围与数据依据

- 仅处理工作表「统计」面板中的图表；页面内图表不属于本领域，不以数据源相同或图表同名混用身份。
- 使用任务绑定的 appId、真实 worksheet_id、chart_id 和所需 viewId；字段必须来自有效结构或已核实的 alias。只补实际缺口，工作表概览使用 MD。
- 工具入参名称、必填项、枚举及组合约束严格依实际 Schema。页面联动 objectId、组件布局和 filtersGroup 不属于工作表统计图配置，不套用页面组件 JSON。

## 共用设计规则与领域边界

- 图表选型、数据源与统计口径统一遵循一并加载的 `hap-chart-design-guide`，本 Skill 不另设类型表。
- 工作表统计图使用自身的筛选和时间范围，不套用页面共享筛选、48 列布局或同排 KPI 卡片规则。局部修改保留未批准的口径与样式。

## 原地修改与验证

- 普通配置修改保持真实 chartId、列表位置、创建者与所属工作表，不删除重建或附带切换公共/个人归属。已知身份时，改名只传 chartName；其余未修改键省略，不先为普通增量属性读取整份配置。
- 明确要求公共/个人切换时使用 `update_chart_owner`，不改统计配置、不额外排序；转个人归原创建者，不支持指定其他人，自定义页面组件不适用。复用已知身份与状态，缺少必要事实才定向查询；权限由接口校验，风险沿用共享安全规则。明确成功即可收口，结果未知先定向核验，不盲目重放。
- 切换 chartType 会清理旧类型配置：先读取当前完整详情，再按新类型提交需要保留的兼容配置，不能假定省略的旧类型专属属性仍在。无法保留批准要求时报告差异，不静默丢弃。
- 详情不是可直接写回的入参。formulas 按写接口契约使用；filter 可能含服务内部运算符及数组包装，修改时按实际输入 Schema 重新构造，未修改筛选时省略 filter。
- 清空说明使用 `description: ""`；清空筛选使用当前 Schema 支持的 `filter: {}`；不使用 null、默认空集合清空其他未批准属性，不向 `update_chart` 回写只读 isPublic、位置或归属字段。
- 类型、维度、指标、筛选、时间等统计语义变更后定向核验，注意不适用参数可能被忽略；按字段映射和规范化后的实际语义比较。普通名称/说明明确成功时不机械回读，不逐项美化或反复切换设计。

## 复制已有图表

- 将图表复制到本工作表统计列表时使用 `move_chart` 的复制模式，保留原图；不传目标页面、不跨工作表迁移。复制到自定义页面或在页面间移动由页面修订执行器处理。
- 来源身份已知时直接使用，缺少 ID 才按所属工作表定位；纯复制不重新生成整份图表配置。复用明确成功返回的新 ID，后续修改作用于副本；结果未知先核验，不盲目重试。
