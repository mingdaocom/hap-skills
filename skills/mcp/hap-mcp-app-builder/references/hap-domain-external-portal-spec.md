# 外部门户视觉与素材规范

## 一、适用范围

设计门户名称/登录页标题、补齐基础外观或优化、美化、重新设计登录页时加载。本规范只负责任务范围内的命名、视觉设计与素材选择，启用授权、跨领域编排和角色权限另按各自规则处理；用户已给定具体属性值时按当前工具契约执行即可。

## 二、命名与视觉设计

- 门户名称（`name`）和登录页标题（`appearance.pageTitle`）按本轮门户的服务对象、使用目的与外部用户任务设计，应用名称仅提供品牌或活动背景，不直接照搬。名称简洁标识入口，标题清楚表达服务用途，两者可相同或互补；用户明确指定的文案优先，已有文案仅在符合本轮目标时复用。例如面向参会者的会务门户可命名“MPC2026 参会服务”，标题为“MPC2026 参会服务入口”；不沿用内部会务管理名称。启用配置同时核对这两个独立字段，修改 `name` 不代表标题已更新；明确只改其中一项时保持另一项。
- 依据应用语义、用户偏好和已有效果，自主选择当前 Schema 支持的布局、Logo 尺寸与背景，不要求用户决定实现细节。需要判断现有素材或布局时定向读取 appearance；重复优化也先比较现状，不机械套用默认值或随意换图。
- 启用任务包含名称与基础外观时，核对并补齐，合适的现状复用；单纯美化不顺带改名称、准入、认证、权限等业务设置。不得用行业类型推断这些安全或业务政策。

## 三、素材优先级与用户沟通

素材按以下顺序选择：

1. 用户本轮明确提供并说明用途的 Logo 或背景图，以及明确要求保留的门户图片；
2. 当前组织 Logo：本轮需选择 Logo 且无上述明确指定时，以已核实的当前应用所属组织 ID 作为 orgId 读取 get_org_detail；返回可用 Logo 就直接使用，不再挑选行业占位 Logo。已有有效结果直接复用，不查询其他组织；组织 Logo 不作为背景图；
3. 现有品牌 Logo、来源不明的现有 Logo 或合适的既有背景；
4. 本规范列出的行业通用资产；
5. 若没有可靠匹配，则不写图片字段，保留平台现有外观。

组织 Logo 使用接口返回的真实图片 URL，按下述 logoSource 流程保存，不伪造附件引用或服务端路径。组织未设置 Logo 时继续按后续优先级选择；查询失败或素材不可用不等于组织没有 Logo，保留现有 Logo 并说明未完成项，不以通用占位图冒充组织品牌。

图片按已交接用途使用，参考图不自动成为背景图；用途仍不明时报告具体缺口，不擅自替代素材用途。没有图片不阻塞普通美化，按上述优先级选取；只有明确要求自有品牌替换却缺少素材时报告未完成，不能以通用图冒充该品牌。用户明确保留的素材优先于默认设计。

只能使用 `patch_portal_config` 当前 Schema 接受的图片来源。对 URL 素材使用 `appearance.logoSource` / `appearance.backgroundSource` 的 URL 来源；服务端负责校验、上传并生成保存路径。图片仅支持 GIF、PNG、JPG、JPEG、BMP，单张不超过 4 MB；SVG、WebP 不作为门户图片来源。不要猜测服务端保存路径。

用户附件通过当前执行环境可用的受控读取方式取得，并按工具 Schema 转换为可接受的图片来源；组织 Logo 直接使用 get_org_detail 返回的真实 URL；下表通用资产使用明确列出的 URL，不猜服务端保存路径。

## 五、视觉交付说明

按实际结果说明布局及使用/保留的素材。使用通用占位 Logo 时告知“当前使用通用占位 Logo，可随时上传品牌 Logo 替换”；通用背景按实际说明，原品牌或来源不明的旧图片不标成占位。不把未提供可选素材列为任务未完成，也不宣称未经验证的跨设备裁剪或图片加载效果。
