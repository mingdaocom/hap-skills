## 二、主题色板

**本色板仅用于定义应用全局主题色（`appColor`）**。必须从以下 9 种精选的 HAP 官方主题色中选取（工作表、自定义页面、AI 助手均自动继承应用主题色，在 `hap-plan.json` 实体对象与创建接口中均无需配置 `color`；不限制字段选项状态色与表单提示文字颜色）：

| Hex 色值 | 视觉感知与推荐业务场景 |
| :--- | :--- |
| **`#A00416`** | **典雅红**。适用于风险控制、警报、高优先级的核心金融或生命科学模块。 |
| **`#F21B65`** | **活力粉**。适用于时尚、零售、社交娱乐、以客户体验为核心的协同板块。 |
| **`#FC532E`** | **温暖橙**。适用于物流配送、现场服务、警示提醒、以及敏捷运营看板。 |
| **`#8E481B`** | **质感棕**。适用于历史档案、物资仓储、重型设备管理、公共资源归档等。 |
| **`#732ED1`** | **睿智紫**。适用于人工智能、高新技术、战略规划、创意设计、前瞻性业务系统。 |
| **`#3054EB`** | **科技蓝**。通用且稳重的主力配色。推荐用于核心业务流水、综合看板、工作量统计。 |
| **`#21710F`** | **生态绿**。适用于环境保护、供应链、农业技术、企业健康度等。 |
| **`#4CAF50`** | **清新绿**。适用于敏捷任务状态（如“正常/已完成”）、日常审批、用户自助服务。 |
| **`#4051B6`** | **商务深蓝**。适用于严谨的 HR 组织架构、合同档案、系统配置表、权限后台。 |


## 三、挑选规则

1. **icon 业务实体优先**：图书→`sys_12_2_book`、订单→`sys_1_2_order`、客户→人物类、仓库→`sys_18_5_warehouse`。
2. **同一 `groupName` 内不雷同**：同组各元素 icon 尽量不同；不同组之间可重复，以业务最贴合为先。
3. **按 type 偏好**：`dashboard`→统计/图表类；`workspace`→工作台/门户类；`aiAssistant`→机器人/智能类。
4. **color 按业务语义**对照上表；同组用相近色系，组间拉开层次。
5. **应用本身（appIcon/appColor）**：挑一个能代表整个系统业务定位的图标 + 主色（如客户管理→人物类 + 玫红，库存→仓库类 + 棕色）。
6. **找不到完全贴合的，选最接近的**，禁止编造 fileName。
