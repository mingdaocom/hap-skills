# Word / Excel 打印模板制作与替换

<!-- SOURCE: skills/hap-domain-print-template-spec/SKILL.md; modify-app/print-template-revision-sub-agent.yaml -->

仅在新建或替换 DOCX/XLSX 文件模板时读取。系统打印、二维码/条码模板配置，以及文件模板改名、权限调整和删除，使用修改手册的对应操作卡，不进入文件制作流程。授权、删除与公开访问边界遵循 [公共安全规则](safety-rules.md)，本规程不扩大修改范围。

## 执行步骤

1. **确认目标和字段**：复用已验证的 worksheetId、templateId、模板类型及用户要求；缺少时定向查询模板列表/详情、`get_worksheet_structure(responseFormat: "md")`。字段映射同时核对真实来源、业务含义和取值类型；缺少必需字段先报告缺口，不编造字段或用常量冒充动态值。沿用用户指定格式和尺寸，不因小纸张、条码或单页要求擅自换格式。
2. **取得原件与素材**：修改时先用 `get_print_template_details(importFile: true)` 获取源文件地址/内容，在临时工作目录另存副本。原件或必要素材不可读时先按 [宿主适配](../HOST_ADAPTER.md) 排查获取方式；仍无法取得、用途不明或复杂对象无法可靠保留时，暂停相关替换并说明缺口；不得用空白文件重建并丢弃原版式、页眉页脚、图片或公式。
3. **制作文件**：使用本地已有文档/表格能力生成 DOCX 或 XLSX，按下表绑定真实 HAP 字段。保留未要求修改的内容、权限和可见范围；Logo、参考图与底图按用户指定用途使用，动态字段和编码保留平台代码。具体排版与图片处理由当前文档工具完成，不为单页效果删减必需内容或静默截断长值。
4. **保存后校验**：重新打开文件，完成下方交付检查；发现缺失、损坏或与要求不符时先修正，无法修正则不创建/替换。纯诊断只报告结果，不发布文件或替换模板。
5. **上传并确认结果**：新建调用 `create_file_print_template`；修改调用 `replace_print_template_file`，保留原 templateId 和格式。`source` 按实时 MCP Schema 使用 `{ "kind": "base64", "fileName": "template.docx", "contentBase64": "<纯Base64字符串>" }` 或合法公网直链 `kind: "url"`；Base64 模式源文件须 **≤ 3 MiB**。文件过大时可在保留内容与清晰度的前提下压缩内嵌图片。文件生成不等于模板保存成功；明确成功后报告实际 ID，结果未知先定向回查模板列表/详情，禁止重复创建或替换来探测结果。

## HAP 占位符速查

仅使用本次需要的语法。示例字段名必须替换成目标表真实字段名、ID 或别名；重名时使用 ID/别名。不得套用其他模板引擎语法，未列格式须有当前平台代码表依据。

| 用途 | 代码与约束 |
|---|---|
| 本表字段 | `#{字段名}` / `#{字段ID}` / `#{字段别名}`；平台不解析 `##{...}`，固定标签的额外 `#` 不得紧贴占位符 |
| 关联/子表字段 | `#{关联字段.目标字段}`；前半段是当前表的关联字段，不是目标工作表 ID，沿真实关系核对 |
| 多值与全部选项 | 多值默认逗号拼接；`#{选项字段_Alloptions}` 含未选项，纵向加 `[V]`；关联代码 `[S]` 表示拼接，需要逐行打印时仅移除对应代码的 `[S]` |
| 附件图片 | `#{附件$[90*auto_H]$}`；尺寸单位 **mm**，支持 `[auto*90]`、`[90*50_auto]`、`[90*50]`，不支持 `auto*auto`；质量 L/M/H，省略时为 L |
| 附件文件名 | `#{附件_name}`；Word 可用 `#{附件$[90*auto_L]$_name}` 同时显示图片与名称，Excel 不支持同时显示；其他附件不因此展开正文 |
| Excel 图片填充 | 多图避免撑高合并单元格时可用 F，如 `#{附件$[auto*20_F]$}`、`#{附件$[auto*90_HF]$}`；F 不是 Word 分页控制 |
| 二维码 | `#{[qrcode]字段$[20*20_H]$}`；固定正方形尺寸，不支持 auto，最多 150 字符且支持中文；L/M/Q/H 是容错率 7/15/25/30，也支持对应数值和百分号写法，不是图片质量 |
| 条形码 | `#{[barcode]字段$[40*10]$}`；Code128 最多 30 字符，支持数字、字母及常用符号，不直接编码中文；也支持 `[40*auto]`、`[auto*10]`、`[40*10_auto]`；加 `_NT` 隐藏下方文字 |
| 系统字段 | 创建人/拥有者：`#{caid}` / `#{ownerid}`；创建/修改时间：`#{ctime}` / `#{utime}`；打印人/时间：`#{printerid}` / `#{ptime}` |
| 链接与记录编码 | 内部链接：`#{[qrcode]privatelink$[20*20]$}`；公开链接：`#{[qrcode]sharelink$[20*20]$}`，必须已有公开访问授权；记录 ID 条码：`#{[barcode]recordid$[40*10]$}` |
| 成员与时间格式 | 成员默认姓名，按授权可用 `#{[member]成员字段ID$[(_ID;_Email;_Phone)]$}`；时间默认 `yyyy-MM-dd HH:mm:ss`，如 `#{ctime$[yyyy/M/d]$}`；不自造 `system.*`、`CNY_UPPER` 等变量或格式 |
| 明细逐行/合并/拼接 | `#{明细字段.子字段}` 放表格数据行逐行填充；`[M]` 合并同列相邻相同值且受前置合并列分组影响；`[S]` 拼接；审批明细取最近一次发起的流程 |
| 固定行与序号 | `#{明细字段[1].子字段}` 取首行，索引加在明细字段后；序号用 `#{关联字段.sequencenumber}` |
| 重复区域 | `#Relation.Repeat[start]#` 与 `#Relation.Repeat[end]#` 包围基本单元，分别独占一行且不与其他内容共用单元格 |
| 空明细不打印 | `#NoDataNotPrint[start]#` 与 `#NoDataNotPrint[end]#` 包围对应区域；不同明细分别使用独立表格和标签，避免其他非空明细带出空区域；这些标记须配对，不按普通字段占位符校验 |

## 交付检查

- **字段与文件结构**：核对字段来源、关联路径、占位符闭合及重复/空明细标记配对；DOCX 跨 run、XLSX 跨富文本片段核对逻辑文本，不跨段落或单元格拼接。重新打开并检查 ZIP/XML 和图片关系有效，图片可解码、使用位置与用途正确，不把“媒体文件存在”当作显示正确。
- **HAP 的 XLSX 兼容要求**：文本使用 `xl/sharedStrings.xml` 及字符串索引，不能交付 `inlineStr`；用现有库保存后也须核对，必要时转换并维护内容类型、关系和索引，保留未修改 ZIP 部件。
- **保真与公式**：对照原件确认未修改内容、页眉页脚、图片、图表、公式、合并区域及打印设置仍保留；不能用 `data_only=True` 的读取结果覆盖公式。缺失缓存不当作零；确需重算时用已有引擎处理临时副本，不刷新外部数据源或破坏链接，重算后重新检查兼容和保真。
- **分页与动态内容**：Word 批量每条另起页时，在模板第一个段落设 `pageBreakBefore`；Excel 批量由平台逐记录导入工作表并分页。另起页不等于内容只占一页，长明细应正常展开。尺寸、方向、缩放、必需内容和编码预留空间按原要求核对，不改要求来通过检查。
- **视觉与验收证据**：本机具备 Office/PDF 渲染能力且改动版式时，查看最终版本的尺寸、分页、截断、字体与图片遮挡；修改后重新检查受影响页。复用现有能力，不为核验临时安装依赖或上传业务文件至外部识别/转换服务。结构检查、Office 预览、HAP 实际填充和扫码分别说明；未做真实数据填充或解码，不宣称单页、动态展开或扫码已通过，没有相应能力则如实保留验收缺口。
